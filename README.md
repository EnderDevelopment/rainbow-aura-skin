# RainbowAura Minecraft Skin

RainbowAura is a unique Minecraft skin featuring a player with light tan skin, half sculk infected, ash blonde hair, and cyan eyes. The standout feature is the rainbow aura hoodie, which adds a vibrant and eye-catching element to the skin. The skin also includes black jeans, completing the look. This skin is perfect for players who want to stand out with a distinctive and colorful appearance.

## Install

1. Download the `player_skin.svg` file from the GitHub repository.
2. Open Minecraft.
3. Navigate to the skins settings.
4. Click on "Open skins folder".
5. Copy the downloaded `player_skin.svg` file into the opened folder.
6. Go back to Minecraft and select the RainbowAura skin from your skins list.

## Use

1. Launch Minecraft.
2. Go to the skins settings.
3. Select the RainbowAura skin from your skins list.
4. Enjoy your new, vibrant Minecraft character with the RainbowAura hoodie.
